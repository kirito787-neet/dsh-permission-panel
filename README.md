# dsh-hotkey-toolkit

DSH 快捷键工具包 + 输入框模型搜索。

## 功能

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+R` | 刷新界面（重新加载渲染进程） |
| `Ctrl+Shift+R` | 重启 DSH Desktop |
| `Ctrl+Alt+1` / `2` / `3` | 切换 兼容模式 / 扩展模式 / 增强模式（可在 设置 → 插件 中自定义） |

- 模型搜索：输入框右侧的模型选择菜单中，列表上方新增搜索框（按模型名 / 模型 ID / 供应商名过滤）。
- 设置页：`设置 → 插件 → 快捷键工具包`，可开关整套快捷键、录制新的模式切换组合键。

## 说明

模式切换会先写入 `dsh-desktop` 设置（切换到非兼容模式时同时关闭浏览器访问与局域网暴露），再重启 DSH Desktop 生效。
模型搜索通过以更低优先级遮蔽官方 `conversation.input.model` 席位实现；若本插件被卸载或出错，官方模型选择会自动恢复。
