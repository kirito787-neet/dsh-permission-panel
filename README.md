# dsh-hotkey-toolkit

DSH 快捷键工具包 + 输入框模型搜索 + 工作区权限面板。

## 功能

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+R` | 刷新界面（重新加载渲染进程） |
| `Ctrl+Shift+R` | 重启 DSH Desktop |
| `Ctrl+Alt+1` / `2` / `3` | 切换 兼容模式 / 扩展模式 / 增强模式（可在 设置 → 插件 中自定义） |

- 模型搜索：点击输入框右侧的模型选择器，菜单**直接打开在模型列表页**，列表上方即搜索框（按模型名 / 模型 ID / 供应商名过滤，回车选中第一个结果）；思考强度入口移到列表首行，一级直达。
- 工作区权限面板：`设置 → 插件 → 工作区权限`，集中管理**所有会话**的权限：
  - 每个会话一行：彩色首字头像 + 会话标题 + 工作目录，运行中的会话带呼吸绿点，「当前」会话带标记；
  - 右侧自绘下拉切换权限预设（仅可查看 / 工作区内修改 / 完全权限），带彩色预设标记与选中勾，通过宿主自带的 `/permission` 命令下发，实时生效；
  - 顶部可修改**新会话的默认权限预设**（写入宿主 `permission` 设置）；
  - 切换到「完全权限」前会弹出风险确认；
  - 下拉为 Portal 渲染、视口内自动翻转避让，支持点击外部 / Esc 关闭；
  - 会话列表支持手动刷新，子会话不出现在列表中。
- 设置页：`设置 → 插件 → 快捷键工具包`，可开关整套快捷键、录制新的模式切换组合键。

## 说明

- 模式切换会先写入 `dsh-desktop` 设置（切换到非兼容模式时同时关闭浏览器访问与局域网暴露），再重启 DSH Desktop 生效。
- 模型搜索通过以更低优先级遮蔽官方 `conversation.input.model` 席位实现；若本插件被卸载或出错，官方模型选择会自动恢复。
- 权限面板读取宿主的 `permissions` 会话投影（会话列表快照自带），切换走 `/permission` 斜杠命令，默认预设走 `permission` 设置命名空间——三者都是宿主原生通道，插件自身不存储任何权限状态。
